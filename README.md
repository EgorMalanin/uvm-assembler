# Ассемблер УВМ — вариант 13

Ассемблер и интерпретатор учебной виртуальной машины (УВМ).
Практическая работа №3, вариант 13. Текущий этап — **Этап 1:
перевод программы в промежуточное представление**.

## Общее описание

Программа читает текст на языке ассемблера в формате YAML,
проверяет корректность мнемоник и операндов согласно спецификации
УВМ и строит промежуточное представление (IR) — список полей
`A`, `B`, `C` каждой команды. В режиме тестирования IR выводится
на экран в формате полей и значений из спецификации.

Формирование двоичного файла выполняется на Этапе 2; путь к нему
уже принимается как аргумент командной строки.

## Требования

- Python 3.8+
- PyYAML

## Спецификация УВМ (вариант 13)

Размер каждой команды — 6 байт, порядок байт little-endian.
Кодирование: `A | (B << shift_B) | (C << shift_C)`.

| Команда | A (биты 0–6) | B | C |
|---|---|---|---|
| Загрузка константы | 77 | Константа, биты 7–15 (9) | Адрес, биты 16–18 (3) |
| Чтение из памяти | 44 | Адрес, биты 7–9 (3) | Адрес, биты 10–12 (3) |
| Запись в память | 90 | Адрес, биты 7–9 (3) | Адрес, биты 10–29 (20) |
| Побитовое «не» | 43 | Адрес, биты 7–26 (20) | Адрес, биты 27–46 (20) |

Семантика команд:

- **Загрузка константы**: операнд — поле B; результат — регистр
  по адресу из поля C.
- **Чтение из памяти**: операнд — значение памяти по адресу,
  который хранится в регистре с адресом C; результат — регистр
  с адресом B.
- **Запись в память**: операнд — регистр с адресом B; результат —
  значение памяти по адресу C.
- **Побитовое «не»**: операнд — значение памяти по адресу C;
  результат — значение памяти по адресу B.

## Язык ассемблера

Исходный файл — YAML-документ с единственным корневым ключом
`program`, значение которого — непустой список инструкций.
Каждая инструкция — отображение с ключом `op` (мнемоника)
и двумя операндами.

| Мнемоника | Операнд → поле B | Операнд → поле C | Диапазон B | Диапазон C |
|---|---|---|---|---|
| `load_const` | `const` | `addr` | 0…511 | 0…7 |
| `read_mem` | `dst_reg` | `src_reg` | 0…7 | 0…7 |
| `write_mem` | `src_reg` | `addr` | 0…7 | 0…1048575 |
| `bit_not` | `dst_addr` | `src_addr` | 0…1048575 | 0…1048575 |

Пример:

```yaml
program:
  - op: load_const
    const: 194
    addr: 6
  - op: bit_not
    src_addr: 510
    dst_addr: 219
```

Все операнды — целые неотрицательные числа. Выход за разрядную
сетку поля считается ошибкой трансляции.

## Аргументы командной строки

| Аргумент | Описание | По умолчанию |
|---|---|---|
| `source` | путь к исходному YAML-файлу | обязательный |
| `-o`, `--output` | путь к двоичному файлу-результату | `program.bin` |
| `-t`, `--test` | режим тестирования: вывод IR на экран | выключен |

## Описание функций

### `src/errors.py`
- `AssemblerError` — базовое исключение.
- `SourceFileError` — файл не найден или недоступен.
- `StructureError` — нарушена структура YAML-документа.
- `InstructionError` — некорректная инструкция.

### `src/spec.py`
- `FieldSpec` — имя операнда, сдвиг и разрядность поля.
- `CommandSpec` — код операции и описания полей B и C.
- `SPECS` — таблица форматов всех команд УВМ.
- `field_limit(width)` — максимальное значение поля разрядности
  `width`.

### `src/loader.py`
- `load_source(path)` — читает файл и возвращает список инструкций.
- `_read_yaml(path)` — открывает файл и разбирает YAML.
- `_extract_program(data)` — извлекает и проверяет секцию `program`.

### `src/assembler.py`
- `assemble(instructions)` — строит промежуточное представление.
- `_assemble_instruction(raw, number)` — транслирует одну команду.
- `_read_opcode(raw, number)` — проверяет мнемонику.
- `_read_field(raw, field, number)` — читает операнд.
- `_check_range(value, field, number)` — проверяет диапазон.

### `src/ir_view.py`
- `format_ir(program)` — форматирует IR как `A=…, B=…, C=…`.

### `src/main.py`
- `build_parser()` — настраивает разбор аргументов.
- `run(args)` — выполняет трансляцию и вывод.
- `main(argv)` — точка входа, обрабатывает ошибки.

## Команды запуска и тестирования

Запуск через скрипт-обёртку:

```bat
run.bat tests\spec_test.yaml -t
run.bat tests\demo_not.yaml -o build\demo.bin
```

Прямой запуск:

```bat
python src\main.py tests\spec_test.yaml --test
```

Полный набор тестов этапа:

```bat
tests\test_stage1.bat
```

## Примеры использования

### Тесты из спецификации УВМ

```bat
python src\main.py tests\spec_test.yaml -t
```

Вывод:

```
A=77, B=194, C=6
A=44, B=4, C=6
A=90, B=1, C=632
A=43, B=219, C=510
```

Поля полностью совпадают с тестами спецификации. Автоматическая
проверка совпадения выполняется тестом 2 в `tests\test_stage1.bat`
сравнением с `tests\expected_ir.txt`.

### Обычный режим

```bat
python src\main.py tests\demo_not.yaml -o build\demo.bin
```

Вывод:

```
Source: tests\demo_not.yaml
Output: build\demo.bin
Instructions: 5
Intermediate representation built successfully
```

```bat
python src\main.py tests\err_range.yaml -t
```


## Этапы разработки

- **Этап 1.** CLI, язык ассемблера на YAML, трансляция в IR,
  вывод полей в режиме тестирования. *(реализовано)*
- **Этап 2.** Формирование машинного кода и запись двоичного файла.
- **Этап 3.** Интерпретатор, модель памяти, дамп в JSON.
- **Этап 4.** АЛУ: побитовое «не».
